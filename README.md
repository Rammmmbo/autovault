# Auto Vault (NeoForge 26.2, client-side)

Opens Trial Chamber vaults automatically when they display a Heavy Core or a Wind Burst book.

- Hold the matching Trial Key / Ominous Trial Key in a hand and look at the vault.
- G toggles the mod.
- Build: `./gradlew build` (JDK 25) -> `build/libs/autovault-1.0.0.jar`
- Test: `./gradlew runClient`
